Components shipped so far

Three pieces, each committed and independently verified against the real dataset — not sample data, not assumptions.

Contract + Adapter Seam done

The internal representation every ingestion front-door reduces to: Patient, Timepoint, ImageRef (lazy, header-only geometry), Space (per-image, not per-timepoint). The Adapter ABC is the two-front-door contract — proven by a real second subclass (DicomAdapter), not just an interface on paper.

src/rano/contract/case.py · src/rano/adapters/base.py · adapters/dicom.py

Verified — a no-data smoke test exercises every type end-to-end: Geometry.from_header derives spacing/orientation/anisotropy correctly on both an isotropic and a thick-slice synthetic case; a fake ImageRef proves the ABC is satisfiable; Patient.__post_init__ rejects out-of-order timepoints; DicomAdapter is a real Adapter subclass whose stub methods raise NotImplementedError as designed.

LUMIERE Adapter done

Resolves LUMIERE-datacompleteness.csv (the ground-truth manifest) + the 32.6 GB imaging zip into lazy Patient objects — streamed via zipfile, no extraction. Wires the mask plus an MNI-space mask_reference and brain_mask beside it, so later alignment checks compare grids that are actually meant to match.

Atlas-Space Consistency Fingerprint done — seed of step 3

A pure, read-only, adapter-agnostic check: does every DeepBraTumIA atlas-space image (mask + reference + brain mask) across the whole cohort actually share one grid? This is the real failure mode a "canonical mask" claim could hide — not whether the label is externally correct.

src/rano/fingerprint/atlas_consistency.py

Verified — 1,773 / 1,773 MNI-tagged images across all 91 patients share an identical affine + shape (182, 218, 182), to floating-point precision. Zero outliers.

Architectural decisions made this piece

DecisionWhy
Validator emits a capability profile, not usable/unusableA router maps profile → action, so the same validator serves LUMIERE (mask absent = failure) and a future raw-DICOM door (mask absent = expected, routes to segmentation)
Adapter seam built now; only LUMIERE implementedDicomAdapter exists as a real ABC subclass (stubbed) so the two-door design is proven, not asserted
Adapter = format-decode only, never processingResample/skull-strip/register/segment stay explicit downstream stages — the loader never transforms pixels
Space lives per-image, not per-timepointLUMIERE masks are MNI, raw sequences are native — comparing them directly would falsely flag every case as misaligned
Single vs multi-timepoint is the router's jobN=1 → segment+store, N>1 → segment+RANO; the loader/validator stay agnostic to it
Patient-025: manifest-authoritative + flagRather than build fragile zip-reconciliation for an 8↔8 label mismatch that can't be safely auto-mapped
External MNI152 identity verification: droppedNothing downstream ever computes against an external reference template — only cohort-internal consistency protects a real failure mode, so that's the only check built
